Sportivo Public Fixture API

Sportivo by Dipesh Sapkota provides public read-only fixture endpoints for the football, cricket, and basketball pages. The data is dynamic and is supplied by the upstream provider.

Endpoints

  • GET /api/matches/football
  • GET /api/matches/cricket
  • GET /api/matches/basketball

Successful responses are JSON arrays. A fixture may contain title or name, category, status, date, startTime, teams, poster, image, thumbnail, and sources. Clients must tolerate missing fields and empty arrays.

Example response

[{"title":"Example Team vs Example Club","category":"football","status":"upcoming","date":"2026-10-14T18:30:00Z","teams":[],"sources":[]}]

Reliability and attribution

Fixture availability, timestamps, statuses, artwork, and stream sources can change. Consumers should implement timeouts, retries with backoff, empty-state handling, and validation. Sportivo does not guarantee stream availability and is not an official league or broadcaster.
