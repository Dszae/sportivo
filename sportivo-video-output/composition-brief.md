# Sportivo Launch Film

## Objective
A premium, factual product launch video for Sportivo using live browser captures and the repository logo.

## Verified product story
Sportivo presents a real-time fixture desk for football, cricket, and basketball. The UI supports searching matches, opening a fixture detail view, and selecting available stream sources. The live API returned real fixtures during capture.

## Visual identity
- Background: #080a0b / #101716
- Text: #f6f7f9
- Accent: #c9f36b
- Secondary accent: #e5b94f
- Type: source UI uses Manrope fallback stack; film uses a clean system sans-serif for reliable local rendering.

## Audio
- Narration: local Kokoro TTS, English US, am_michael, generated as sportivo-voiceover.wav.
- Music: bundled `music.mp3` from the Brag skill asset library, mixed under narration.
- Captions: manually timed to the final script and kept in the lower safe zone.

## Storyboard
1. 0.0-3.2: dark brand hook, logo and “Every match brings a moment.”
2. 3.2-8.5: desktop capture enters with “The fixture desk, closer.”
3. 8.5-15.5: real category/search UI with sport labels and “Browse. Search. Find.”
4. 15.5-21.5: zoom into live schedule cards and stream-oriented benefit copy.
5. 21.5-27.0: brand close, URL, and “Stay close to the moment.”

All product claims are derived from source UI, README, or live API behavior. No broadcast footage or invented statistics are used.
