Sportivo is a focused web application for discovering sports fixtures, checking match timing, and finding available stream sources. It brings football, cricket, and basketball schedules into one responsive fixture desk. The application is designed for people who want a clear view of what is happening next without navigating through a crowded sports news site. Sportivo presents the match title, sport category, local start time, current status, team information, poster or team imagery when available, and the stream options returned for that event.

The product is created and maintained by Dipesh Sapkota. Sportivo is an independent web project published at sportivo.dipeshsapkota7.com.np and connected to Dipesh Sapkota's portfolio and professional profiles. The project demonstrates a practical sports interface built with React and Vite, with deployment configuration for Vercel and a remote fixture data source. The interface is intended to be quick to scan on a desktop computer, tablet, or mobile phone while keeping the most important match information close to the user.

Football fixtures and match discovery

The football view is available at Sportivo football fixtures. It lists available football events and helps visitors search for a club, national team, competition, or match title. A fixture can represent a scheduled game, an event in progress, or a completed result, depending on the status supplied by the data provider. Common football matchups are displayed with the participating teams, the available time in Nepal, and a clear indication when an event is live or finished.

Cricket fixtures and event schedules

The cricket view is available at Sportivo cricket fixtures. Cricket events can have different naming formats from football matches, so Sportivo preserves the supplied event title and category while presenting it in the same easy-to-scan schedule. Visitors can use the search field to find a tournament, country, team, or event. The schedule can change as new fixtures become available and as existing events move from upcoming to live and then to completed.

Basketball fixtures and local kickoff times

The basketball view is available at Sportivo basketball fixtures. Basketball visitors can browse upcoming events, search by team or event name, and open a fixture to inspect the available stream sources. Sportivo formats timestamps for the Nepal time zone, Asia/Kathmandu, so visitors in Nepal can understand when a match begins without manually converting an international schedule.

How the Sportivo fixture desk works

  1. Choose football, cricket, basketball, or the main Sportivo schedule.
  2. Browse the returned fixture cards or search for a team and match.
  3. Review the event title, sport, local Nepal time, and live or completed status.
  4. Open a fixture to request its available stream details.
  5. Select a valid available source when the event provider supplies one.

Sportivo does not claim that every scheduled event will have a stream. Availability depends on the upstream event data and source provider. If an event has no source, if a source is offline, or if a remote response cannot be parsed, the application communicates that state instead of presenting a misleading link. The site also validates external stream URLs before using them and opens external destinations with browser security protections.

Sports schedule information for visitors in Nepal

Sportivo is especially useful for visitors who follow international sports from Nepal. Match times are formatted with the Asia/Kathmandu time zone and the en-NP locale, giving the schedule a familiar local reference. This helps reduce confusion when a football match, cricket fixture, or basketball game is announced by an international provider in a different time zone. The displayed time is a presentation of the supplied event date and should be checked against the official competition or broadcaster for last-minute changes, postponements, venue changes, and cancellations.

The schedule is designed for repeated daily use. A visitor can open the home page for the main fixture desk, choose a sport from the navigation, scan the current list, and search within the loaded fixtures. Event cards distinguish upcoming fixtures from live events and completed results. When the upstream data contains team logos, posters, or other artwork, Sportivo uses that information to make the fixture easier to recognize. When artwork is unavailable, the interface keeps the event title and schedule usable instead of treating an image as required information.

Search, sharing, and fixture URLs

Sportivo supports team and match discovery through its search field. Search is intended for practical terms such as a club name, national team, tournament, league, or event title. Opening a fixture updates the browser URL with a readable match identifier, which makes the current selection easier to share and return to. A shared fixture URL can load the same application route and attempt to find the matching event in the current schedule. Because fixtures are live data, an old shared event may no longer be returned by the provider after the match has finished or the schedule has changed.

Technology behind the application

The Sportivo interface is built with React and Vite. React controls the interactive schedule, category navigation, search state, fixture selection, stream-source state, loading messages, and error messages. Vite produces the browser bundle and the initial HTML document. Vercel hosts the deployed site and routes the application programming interface requests used to retrieve fixture and stream data. The direct information in this document is intentionally available before the React bundle executes, while the current match list remains dynamic and is loaded from the application data service.

The application uses ordinary semantic page elements such as headings, paragraphs, navigation links, lists, article regions, labels, and accessible names for interactive fixture cards. It supports keyboard activation for fixture cards and uses descriptive image alternative text when images are available. These details help people using assistive technology and help automated systems identify the difference between the site identity, sport navigation, product explanation, fixture schedule, and creator information.
